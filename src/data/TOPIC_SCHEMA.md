# Формат темы курса (src/data/topics/*.js)

Каждый файл: `export default [ {...}, ... ]`. Одна тема ≈ 1–3 параграфа учебника.

```js
{
  id: 'peter-i-reforms',               // латиница, kebab-case, уникальный
  course: 'rus-8',                     // id курса из courses-meta.js
  chapter: 1,                          // номер главы учебника (из courses-meta.js)
  order: 3,                            // порядок темы внутри главы
  paragraphs: '§ 5–6',                 // параграфы учебника, которые покрывает тема
  title: 'Реформы Петра I',
  period: '1699–1725 гг.',             // хронологические рамки для показа
  year: 1699,                          // число для сортировки/поиска
  summary: '1–2 предложения (до ~220 символов).',
  intro: 'Вводный абзац 3–5 предложений: о чём тема, почему важна.',
  sections: [                          // 4–7 подробных разделов — основной текст конспекта
    {
      id: 's1',                        // s1, s2, ...
      title: 'Военная реформа',
      paragraphs: ['Абзац 3–6 предложений.', 'Ещё абзац.'],   // 1–3 абзаца
      list: ['Пункт', 'Пункт'],        // необязательно: перечень (реформы, итоги, условия договора…)
    },
  ],
  people: [{ name: 'Пётр I', years: '1672–1725', role: 'царь с 1682 г., первый российский император (с 1721 г.)' }], // 3–7
  terms: [{ term: 'Рекрутская повинность', definition: 'Понятное определение 1–2 предложения.' }],             // 5–10
  dates: [{ date: '1700', text: 'Начало Северной войны' }],   // 6–12, по порядку
  table: {                             // необязательно, но желательно, если тема «табличная»
    title: 'Основные реформы Петра I',
    columns: ['Сфера', 'Что сделано', 'Итог'],
    rows: [['Армия', '…', '…']],
  },
  map: {                               // необязательно; только если в теме есть география (походы, битвы, города)
    title: 'Северная война 1700–1721 гг.',
    points: [                          // координаты СОВРЕМЕННЫХ мест, проверь их! lat/lng десятичные
      { name: 'Нарва', lat: 59.377, lng: 28.19, type: 'battle', date: '1700', text: 'Поражение русской армии' },
    ],                                 // type: battle | city | capital | event | place
    routes: [                          // необязательно: маршруты походов (массив точек [lat, lng])
      { name: 'Прутский поход', path: [[55.75, 37.62], [47.0, 28.8]], dashed: false },
    ],
  },
  facts: ['…', '…', '…', '…', '…'],   // РОВНО 5 интересных фактов
  significance: 'Абзац: итоги и историческое значение.',
  quiz: [                              // 6–8 вопросов, 4 варианта, answer — индекс 0–3
    {
      question: '…?',
      options: ['A', 'B', 'C', 'D'],
      answer: 2,
      explanation: '1–2 предложения: ПОЧЕМУ это правильный ответ (с опорой на материал).',
      section: 's1',                   // где в теме ответ: s1…sN | terms | dates | people | map | table | facts | significance
    },
  ],
  exam: { ege: true, oge: true },      // входит ли тема в ЕГЭ / ОГЭ (ОГЭ — только до 1914 г.)
  tasks: [                             // 4–6 заданий в формате ЕГЭ/ОГЭ (см. ниже)
  ],
}
```

## Задания в формате ЕГЭ/ОГЭ (`tasks`)

Общие поля: `type`, `exam: ['ege','oge']` (или одно), `text` (условие как в КИМ), `explanation` (разбор: почему такой ответ, с датами/фактами).

- **match** — соответствие (как ЕГЭ № 1, 3, 5, 7; ОГЭ № 1): `leftTitle`, `rightTitle`, `left` (3–4 позиции, без букв в тексте), `right` (5–6 вариантов, без цифр в тексте — лишние варианты обязательны), `answer: '3152'` — для А, Б, В, Г по порядку номера из правого столбца (1-based).
- **sequence** — хронология (ЕГЭ № 2, ОГЭ № 2): `items` (3–4 события), `answer: '312'` — номера в правильном порядке от раннего к позднему. События должны быть в РАЗНЫЕ годы.
- **multi** — выбор нескольких верных (ЕГЭ № 6, 12; ОГЭ № 4, 13): `options` (5–6 утверждений), `answer: '135'` — номера верных по возрастанию; в `text` укажи, сколько верных («Выберите три верных суждения»).
- **term** — термин/название/имя (ОГЭ № 3, ЕГЭ № 9–11): `answer: ['опричнина']` — список допустимых написаний (без учёта регистра и «ё»).
- **single** — одна цифра (ОГЭ № 5 «лишний термин», 11, 14–17): `options` (4–5 вариантов), `answer: '3'` (1-based номер).
- **map** — вопрос по карте (ЕГЭ № 9–12, ОГЭ № 8–10): `map: { points: [...], routes: [...] }` (как выше; подписи будут скрыты — точки покажутся номерами 1, 2, 3…), текст вопроса ссылается на номера. Ответ: либо `accept: ['Нарва']` (слово), либо `options` + `answer: '2'` (цифра).

Требования: всё проверяемо по материалу темы и общепринятым фактам; однозначный ответ; даты по России до 1918 г. — по старому стилю (новый — в скобках, где важно). Не копировать задания из сборников — только собственные в формате ФИПИ.
