# Задания по номерам КИМ (файлы `src/data/kim/*.js`)

Задания, которые закрывают номера КИМ ЕГЭ и ОГЭ 2026, не выраженные обычными типами из `TOPIC_SCHEMA.md`.
Каждый файл: `export default [ ...задания ]`. Каждое задание привязано к теме курса и к номеру КИМ.

```js
export default [
  {
    topic: 'r8-peter-reforms',   // id существующей темы (src/data/topics)
    kim: 'ege-4',                // экзамен и номер задания КИМ 2026
    type: 'grid',                // тип (см. ниже)
    text: 'Заполните пустые ячейки таблицы…',
    // …поля типа…
    explanation: 'Разбор: почему такой ответ, с датами и фактами.',
  },
]
```

Общие необязательные поля любого задания:
- `source: { title: 'Из указа Петра I (в современном изложении)', text: '…' }` — отрывок исторического источника.
  Для задания с двумя источниками (ЕГЭ № 17) — `sources: [{ title, text }, { title, text }]`.
  Текст — не длиннее ~120 слов; древние и старые документы (до XX в.) можно давать в сокращении, современным языком;
  документы XX в. — только в собственном пересказе. Указывай в `title`: «(в сокращении)» / «(в пересказе)».
  В тексте источника НЕ называй прямо то, что спрашивается (год, имя), — иначе задание решается без знаний.
- `image: 'Описание изображения…'` — текстовое описание изображения (плакат, медаль, марка, картина, памятник), как если бы
  ученик видел картинку: что изображено, какие надписи и даты видны. 2–4 предложения. Сайт покажет его в рамке «Изображение».

## Поля типов

- **grid** (ЕГЭ № 4): `columns` — 3 заголовка (например `['Географический объект', 'Событие', 'Время (век, год)']`);
  `rows` — 3–4 строки по 3 ячейки; ячейка — строка или `'?'` (пропуск). Ровно **6** пропусков; буквы А–Е ставятся
  автоматически по порядку чтения (слева направо, сверху вниз). `options` — 8–9 вариантов для вставки (лишние обязательны);
  `answer: '425917'` — номера вариантов для А, Б, В, Г, Д, Е. Цифры не повторяются.
  В каждой строке должен остаться хотя бы один заполненный элемент (подсказка).
- **multi** (ЕГЭ № 6, 12; ОГЭ № 13): `options` — 6 суждений (ОГЭ № 13 — 5 названий памятников), `answer: '25'` — номера
  верных по возрастанию; в `text` — «Выберите два суждения из шести предложенных». Для ЕГЭ № 12 — `map` с полями как в
  TOPIC_SCHEMA.md (points с lat/lng, routes); на карте точки покажутся номерами, подписи скрыты — суждения должны
  проверяться по карте + знаниям («Город, обозначенный на схеме цифрой 2, …»).
- **term** (ЕГЭ № 8): `answer: ['Сталинград', 'Сталинградская битва']` — допустимые написания.
- **single** (ОГЭ № 11, 14): `options` — 4 варианта, `answer: '3'`.
- **thesis** (ОГЭ № 6): `sentences` — 4 предложения вперемешку: 2 тезиса (обобщающие утверждения) и 2 факта (конкретные
  события/даты, которые их подтверждают). `answer: '3142'` — тезис 1, факт к нему, тезис 2, факт к нему.
  Пары можно записать в любом порядке — проверка это учитывает. В `text`: «Прочтите предложения. Какие из них являются
  тезисами, а какие — фактами, которые можно использовать для аргументации этих тезисов? Запишите номера: тезис, факт,
  тезис, факт».
- **stats** (ОГЭ № 7, только XVIII — начало XX в.): `data: { title, columns, rows }` — статистическая таблица (только
  общепринятые, проверяемые цифры, например численность населения по ревизиям, выплавка чугуна, протяжённость железных
  дорог; допускается «по оценкам» в title); `statements` — 3 суждения, в каждом ровно один пропуск `___`; буквы А, Б, В
  ставятся по порядку; `options` — 5–6 вариантов вставки; `answer: '314'`.
- **scheme** (ОГЭ № 12): `scheme: { top: 'Центральные органы власти при Петре I', items: ['Сенат', '___', 'Синод'] }` —
  верхний блок и 2–5 нижних, ровно в одном из них пропуск `___` (можно с пояснением: `'___ (1538–1547)'`); `answer: ['коллегии', 'коллегия']` — допустимые написания.
- **open** (часть 2): `text` — вопрос как в КИМ (с требованиями: «Укажите…», «Приведите два…», «Объясните…»);
  `points` — максимальный балл (см. таблицу); `criteria` — массив строк с правилами оценивания
  (например `'Указаны век и правитель — 2 балла'`, `'Указан один элемент — 1 балл'`, `'Ответ неправильный — 0 баллов'`);
  `sample` — массив строк: элементы правильного ответа (эталон), как в критериях ФИПИ («Могут быть приведены: …»).
  Ученик пишет ответ сам, затем сравнивает с эталоном и ставит себе балл.

## Требования

- Всё проверяемо по материалу темы и общепринятым фактам; ответ однозначный; даты по России до 1918 г. — по старому стилю.
- Формулировки — как в КИМ ФИПИ 2026. Задания СОБСТВЕННЫЕ, не копии из сборников, демоверсий, «Решу ЕГЭ».
- Тон нейтральный, фактический; для современной истории — по учебникам Мединского (с атрибуцией оценок: «в учебнике…»).
- Строки в одинарных кавычках, в тексте кавычки «ёлочки», апостроф ' не используй.
- Проверка: `node scripts/validate-kim.mjs <файл>.js` → «Все задания КИМ прошли проверку ✓».
