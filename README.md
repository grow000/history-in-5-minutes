# История за 5 минут

Учебный сайт, где ключевые события мировой истории — от Древнего мира до XXI века — объясняются коротко и понятно. Выбери событие, прочитай конспект за несколько минут и проверь себя в мини-викторине.

**Демо:** https://grow000.github.io/history-in-5-minutes/

## Возможности

- **Каталог событий** с поиском (по названию, году, личностям, региону) и фильтрами по эпохам и темам; сортировка по хронологии.
- **Страница события**: что произошло, причины, ход событий, ключевые личности, хронология, 5 важных фактов и значение. Содержание с подсветкой текущего раздела и индикатором прочтения.
- **Викторина из 5 вопросов**: варианты перемешиваются, после каждого ответа — пояснение, в конце — результат и разбор ошибок. Можно отвечать клавишами 1–4 и Enter.
- **Прогресс** — лучший результат по каждой викторине сохраняется в браузере (без регистрации и сервера).
- Светлая и тёмная темы, адаптивная вёрстка для телефонов, плавные анимации (с учётом настройки «уменьшить движение»).

## Эпохи

| Эпоха | Период |
|---|---|
| Древний мир | до V века |
| Средние века | V–XV века |
| Новое время | XVI–XIX века |
| Новейшее время | XX век |
| XXI век | с 2001 года |

## Запуск

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev      # режим разработки: http://127.0.0.1:5173
npm run build    # сборка в папку dist
npm run preview  # просмотр собранной версии
npm run check    # проверка данных всех событий
```

## Технологии

React 18, Vite, React Router (HashRouter — сайт работает на любом статическом хостинге), чистый CSS с переменными. Никакого backend.

## Структура

```
src/
  data/
    events/*.js   — события (по файлу на эпоху)
    index.js      — эпохи, темы, поиск и фильтрация
    SCHEMA.md     — формат события
  pages/          — Главная, Событие, Викторина, О проекте, 404
  components/     — шапка, подвал, карточка события
  styles.css      — все стили
scripts/validate.mjs — автоматическая проверка контента
```

## Как добавить событие

Добавь объект в любой файл из `src/data/events/` по формату из [`src/data/SCHEMA.md`](src/data/SCHEMA.md) и запусти `npm run check`. Новое событие автоматически появится в каталоге, поиске, фильтрах и викторинах.
