# История за 5 минут

Учебный сайт по истории: полный курс истории России по учебникам **В. Р. Мединского и А. В. Торкунова** (6–11 классы) и всеобщей истории по учебникам **В. Р. Мединского и А. О. Чубарьяна** (5–11 классы), подготовка к **ЕГЭ и ОГЭ** по всем номерам заданий в формате ФИПИ.

**Демо:** https://grow000.github.io/history-in-5-minutes/

## Разделы

- **Темы и события** — поиск любого события или темы и сборники всех тем ЕГЭ и ОГЭ по разделам кодификатора ФИПИ (без деления на классы и учебники). Каждая тема — короткая интерактивная история: рассказ с вопросами на понимание, «Где это было», карточки-перевёртыши с героями и терминами, игра «расставь события по порядку», факты, итог и тест. За действия начисляется опыт (XP).
- **ЕГЭ и ОГЭ** — банк заданий по **всем номерам КИМ 2026**: ЕГЭ № 1–21 и ОГЭ № 1–24. Часть 1 проверяется автоматически по правилам ФИПИ (таблица № 4 — до 3 баллов, тезисы и факты, статистика, схемы, источники, изображения), часть 2 — самопроверка по эталону и критериям. Конструктор вариантов по номерам, вариант «как на экзамене» (часть 1 или полный).
- **Источники** — список учебников и пособий, на которых основан материал.

В тестах после каждого ответа объясняется, почему верен правильный вариант, а по ошибкам предлагается дополнительный материал — прямая ссылка на нужный раздел конспекта.

## Источники

- Мединский В. Р., Торкунов А. В. «История России», 6–9 классы (Просвещение, 2025) и 10–11 классы, базовый уровень (Просвещение, 2023).
- Мединский В. Р., Чубарьян А. О. «Всеобщая история», 5–11 классы (Просвещение, 2023–2025).
- ФИПИ: демоверсии, спецификации и кодификаторы ЕГЭ и ОГЭ по истории 2026 г.
- Типовые экзаменационные варианты ЕГЭ и ОГЭ по истории под ред. И. А. Артасова (Национальное образование, 2026) — как образец формата заданий.

Конспекты — авторский пересказ для повторения, а не копия учебников; задания — собственные, в формате ФИПИ.

## Запуск

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev      # режим разработки: http://127.0.0.1:5173
npm run build    # сборка в папку dist
npm run check    # проверка всех тем и заданий
```

## Технологии

React 18, Vite, React Router (HashRouter), Framer Motion (анимации и вкладки), Leaflet (карты), Lucide (иконки), чистый CSS с переменными. Без backend: прогресс хранится в браузере.

## Структура данных

```
src/data/
  courses-meta.js   — курсы, главы и параграфы учебников, источники, сведения об экзаменах
  topics/*.js       — темы курса (формат — TOPIC_SCHEMA.md), внутри — тесты и задания ЕГЭ/ОГЭ
  kim/*.js          — задания по номерам КИМ: части 1 и 2 (формат — KIM_SCHEMA.md)
  kim-spec.js       — номера КИМ ЕГЭ/ОГЭ 2026, типы и баллы
scripts/            — автоматическая проверка контента (npm run check)
```
